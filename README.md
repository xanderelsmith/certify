# certify

Educators Forum September 2025 - Registration & Certificate Issuance Portal.

## Features
- Participant registration matching official Lagos State Educators Forum format.
- Interactive visual drag-and-drop certificate layout designer.
- On-the-fly personalized PDF certificate generation.
- Results dashboard with search, filtering, inline preview, 1-click PDF download, and batch ZIP export.
- Google Form response hook, scraper, and auto-sync.
